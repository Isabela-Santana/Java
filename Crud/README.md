🚀 Java CRUD (In-Memory User Management)
Este é um sistema de CRUD (Create, Read, Update, Delete) simples desenvolvido em Java para gerenciamento de usuários. O projeto utiliza armazenamento em memória (Listas) e demonstra conceitos fundamentais de Programação Orientada a Objetos (POO), tratamento de exceções e manipulação de datas modernas com Java Time API.

📋 Funcionalidades
O sistema permite realizar as seguintes operações:

Cadastrar Usuário: Salva nome, e-mail e data de nascimento (gera ID automático).

Atualizar Usuário: Altera os dados de um usuário existente através do seu ID.

Excluir Usuário: Remove um registro do sistema.

Buscar por Identificação: Localiza um usuário específico pelo ID.

Listar Todos: Exibe todos os usuários cadastrados no console.

🛠️ Tecnologias Utilizadas
Linguagem: Java 17+

Armazenamento: ArrayList (Em memória)

Tratamento de Datas: OffsetDateTime e LocalDate

Estrutura: Padrão DAO (Data Access Object)
